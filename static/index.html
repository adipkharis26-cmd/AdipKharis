2. Konfigurasi OAuth Consent Screen Pilih User Type: External. Pada bagian Test Users, tambahkan email YouTube Anda.
3. Buat Kredensial OAuth Client ID Pilih Web application. Pada Authorized redirect URIs:
4. Simpan & Hubungkan! Masukkan Client ID & Secret di tab Pengaturan, lalu klik "+ Hubungkan Channel".

Buka BGRis Media di HP

Anda dapat membuka dan mengontrol dashboard ini langsung dari browser HP (Chrome, Safari, dll.) yang terhubung ke Wi-Fi yang sama.

Ketik alamat di atas pada aplikasi browser di HP Anda.
HP Mengalami Loading / Muter-Muter Terus?
  1. Wi-Fi yang Sama: Pastikan HP terhubung ke Wi-Fi yang sama dengan Laptop (bukan kuota data seluler).
  2. Izin Firewall Windows: Windows Defender Firewall memblokir koneksi dari luar. Jalankan file izinkan_akses_hp.bat di folder aplikasi (Klik kanan → Run as administrator).
