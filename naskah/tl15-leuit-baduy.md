# TL15 — Kenapa Lumbung Padi Ini Dibangun Jauh dari Rumah?

**Skill:** v4 retensi (frame 0 dramatis, judul pernyataan, akhiran loop).

**Hook:** Api melahap satu kampung. Rumah-rumah habis jadi abu. Tapi warganya tidak kelaparan. Padi mereka disimpan... jauh dari rumah.

---

## Beat 1 — Hook (frame 0: kampung terbakar + wajah kaget)

Api melahap satu kampung. Rumah-rumah habis jadi abu. Tapi warganya tidak kelaparan. Padi mereka disimpan... jauh dari rumah.

## Beat 2 — Konflik

Seminggu sebelumnya, Raka, mahasiswa dari kota, tertawa melihat lumbung berjajar di luar kampung Baduy. "Ki, padi kok ditaruh jauh-jauh? Nanti dicuri orang!"

## Beat 3 — Rahasia leluhur

Jadi begini. Di Baduy, tiap keluarga wajib punya leuit, lumbung padi berkaki. Pesan leluhurnya: rumah boleh berdempet, leuit harus menjauh.

## Beat 4 — Penjelasan sains

Soalnya, rumah kayu beratap daun kering gampang tersambar api dari satu tungku. Kalau lumbung di samping rumah, api membawa rumah dan makanan sekaligus. Jarak membuat percikan api tak sampai.

## Beat 5 — Lapisan kedua

Gabah disimpan masih bertangkai, terlindung kulitnya, di lumbung panggung yang kering. Peneliti mencatat, padi di leuit bisa bertahan puluhan tahun. Tapi saat rumah merapat ke lumbung, kebakaran dua ribu tujuh belas menghanguskan ratusan leuit.

## Beat 6 — Perubahan

Pagi setelah kebakaran, Aki Sarpin membuka leuitnya. Padinya utuh. Sekarang, Raka yang paling cerewet melarang orang membangun dekat lumbung.

## Beat 7 — Akhiran loop (v4, tanpa CTA)

Karena di kampung kayu, cukup satu bara dari tungku yang lupa dipadamkan...

Kalimat terakhir menggantung dan menyambung ke kalimat pertama ("Api melahap satu kampung…"). Visual akhir: bara tungku memercik ke atap daun, komposisi sama dengan frame 0.

## Dasar fakta

- Leuit = lumbung padi masyarakat Baduy (Kanekes, Lebak, Banten). Setiap keluarga diwajibkan adat memiliki leuit; padi di leuit adalah cadangan paceklik, bukan untuk dijual. Sumber: [Jurnal Biodjati UIN SGD, "Kearifan Ekologi Orang Baduy dalam Konservasi Padi dengan Sistem Leuit"](https://journal.uinsgd.ac.id/index.php/biodjati/article/view/1289), [Jurnal MIMBAR Unisba](https://ejournal.unisba.ac.id/index.php/mimbar/article/downloadSuppFile/3415/426), [ANTARA](https://bengkulu.antaranews.com/berita/293688/petani-badui-penuhi-pangan-dari-panen-padi-huma?page=all).
- Leuit dibangun terpisah dari permukiman (seberang sungai, lereng, atau 10–20 m dari rumah terakhir) agar bila rumah tertimpa musibah, persediaan pangan tetap ada. Sumber: [Jurnal Dinamika Hukum Unsoed](https://dinamikahukum.fh.unsoed.ac.id/index.php/JDH/article/download/1606/551).
- Kebakaran Kampung Cisaban, Baduy Luar, 23 Mei 2017: sekitar 84 rumah dan 200-an leuit terbakar; kajian menyebut permukiman yang terus melebar membuat jarak leuit–rumah tidak lagi sesuai hukum adat. Ditulis "ratusan leuit". Sumber: Jurnal Dinamika Hukum (di atas).
- Padi disimpan sebagai gabah bertangkai (belum digiling); leuit berupa panggung beranyaman bambu (sirkulasi udara, tikus sulit naik). Daya simpan "puluhan tahun" (Biodjati: lebih dari 50 tahun; UI Paradigma: sepuluh tahun lebih). Ditulis "bisa bertahan sampai puluhan tahun", bukan angka pasti. Sumber: Biodjati; [UGM](https://ugm.ac.id/en/news/ugm-students-research-rice-barns-leuit-with-100-year-shelf-life-in-badui-tribe/); [Paradigma UI](https://scholarhub.ui.ac.id/paradigma/vol13/iss2/3).
- Sains: kulit gabah melindungi beras dari jamur, serangga, dan oksidasi; ruang berkaki berventilasi menjaga gabah kering. Jarak memutus rambatan api dan percikan bara antarbangunan kayu beratap daun.
- Kebakaran di awal video adalah adegan fiksi, bukan peristiwa tertentu. Tokoh Aki Sarpin dan Raka fiksi. "Aki" = sapaan kakek dalam bahasa Sunda.
- Hindari: klaim "100 tahun" sebagai pasti; jangan menggambarkan Baduy Dalam (busana putih) karena aturan dokumentasinya ketat. Tokoh digambarkan sebagai Baduy Luar (hitam/biru, ikat kepala biru).
