ATURAN GAYA (wajib):
- Karakter: Quibble (kapsul toska, emosi lewat alis) & Snick (segitiga koral, licik). Flat 2D, outline tebal, palet tetap. Tanpa dialog, tanpa teks di layar.
- Durasi 13–15 dtk, 30 fps, 1080×1920.
- Hook: frame 0 sudah bergerak, konflik terbaca < 1 dtk.
- Retensi: ada gag/kejadian tiap 1–2 dtk, usaha makin meningkat, payoff palsu lalu twist. Variasikan siapa yang menang.
- SEAMLESS LOOP: frame terakhir harus menyambung mulus ke frame 0 (gerakan, posisi, zoom, kecepatan, elemen latar berulang). Audio dimix melingkar supaya tidak ada jeda di titik loop. Cek frame (akhir-20…akhir) + (0…10) sebelum final.
- Safe zone: aksi penting di luar 20% bawah dan kolom kanan bawah (UI Shorts); lantai di ~65% tinggi layar.

AUDIO:
- ElevenLabs Sound Effects lewat proxy sesi (key sudah tersimpan sebagai network secret untuk api.elevenlabs.io; di kode pakai placeholder `proxy-injected`, JANGAN tulis key di repo/chat).
- Cek kuota dulu (GET /v1/user/subscription). Satu episode ±300 kredit. Kalau kuota tidak cukup: JANGAN generate, laporkan.
- Musik & SFX instrumental tanpa vokal berbahasa. Dilarang lagu/klip berhak cipta.

SETUP TEKNIS:
- `cd global-shorts/video && npm install`; `pip install numpy scipy`.
- Remotion memakai Chromium bawaan sesi (lihat remotion.config.ts).
- Render: `npx remotion render src/index.ts <ID> out/<nama>.mp4 --codec=h264 --crf=18`. Target loudness ±-14 LUFS, puncak ≤ -1 dB.
